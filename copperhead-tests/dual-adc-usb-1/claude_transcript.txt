❯ what sources does copperhead use for part selection?                          

  Read 2 files, ran 6 shell commands (ctrl+o to expand)

● copperhead picks parts from two places: the model's own memory, and the stock
  KiCad symbol libraries installed on this machine. It doesn't look anything up
  in datasheets, distributor catalogs or on the web.

  - The model's memory. The stage-3 prompt (src/commands/create.ts:188) asks the
    model to choose parts, mark every part number "UNVERIFIED", and give a
    reason that could be checked against a datasheet. Nothing in the pipeline
    reads a datasheet. That's why figures like the LTC2290's ±12 mV offset are
    labelled "from memory".
  - Web search is blocked. The Claude Code backend turns off all of Claude
    Code's built-in tools, including WebSearch and WebFetch
    (src/agent/providers/claude-code.ts:95-106). The model can only use
    copperhead's own tools.
  - Installed KiCad symbols. Three tools check the libraries: search_symbols
    (does a symbol exist), symbol_pins (what its pins are) and verify_symbols.
    The prompt requires every active part to have an installed symbol and tells
    the model to swap in a part that has one. That's where the substitutions
