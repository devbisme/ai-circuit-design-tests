# Setup

* Install [konnect](https://github.com/mixelpixx/Konnect/releases/download/v0.12.1/konnect-v0.12.1-x86_64-unknown-linux-gnu.tar.gz). Then run `konnect init` to install the skills, MCPs, etc. used by Claude Code.

* Install the [Konnect KiCad plugin](https://github.com/mixelpixx/Konnect/releases/download/v0.12.1/konnect-pcm-v0.12.1-linux.zip). Then start PCBNEW and click on the `Tools => External Plugins => Konnect`. Click on the `Start Server` button in the `Konnect Settings` window to initiate the channel that Claude Code will use to communicate with PCBNEW.
