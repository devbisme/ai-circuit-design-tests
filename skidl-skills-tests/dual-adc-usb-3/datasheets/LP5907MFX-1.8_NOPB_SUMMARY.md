# LP5907MFX-1.8/NOPB — TI 250mA Low-Noise, Low-IQ LDO, fixed 1.8V output, SOT-23-5 (U4)

Source: `datasheets/LP5907MFX-1.8_NOPB.pdf` (TI SNVS798Q, Rev. Q, July 2025, full document,
downloaded directly from ti.com this phase). **Also covers `LP5907MFX-3.0` (U6)** — same
family/package/pinout, only the fixed output-voltage trim differs (TI ships LP5907 in 25mV
steps from 1.2V to 4.5V, factory-trimmed per order code; -1.8 and -3.0 are just two trim
options of the identical die/pinout) — one datasheet, one summary covers both BOM lines.

| Spec | Value |
|------|-------|
| Package | SOT-23-5 (DBV), 2.9×2.8mm — matches sourced footprint `Package_TO_SOT_SMD:SOT-23-5` |
| Vcc / Vin range | 2.2V–5.5V input |
| Key output spec | Fixed output: **1.8V for U4** (`-1.8` order code) / **3.0V for U6** (`-3.0` order code), ±2% tolerance, up to 250mA; PSRR 82dB @ 1kHz, output noise <6.5µVrms, no noise-bypass cap needed |
| Max current / power | 250mA max output; IQ (enabled) 12µA typ — very low quiescent |
| Operating temp | Junction temp –40°C to 125°C |

## Pinout (DBV / SOT-23-5, Table 4-2, Fig. 4-3)

| Pin | Name | Function |
|-----|------|----------|
| 1 | IN | Input voltage supply — connect a 1µF capacitor at this input |
| 2 | GND | Common ground |
| 3 | EN | Enable input. Low (<VIL) = off, output discharged to GND through internal 230Ω pulldown. High (>VIH) = on. **Internal 1MΩ pulldown holds the regulator off by default if EN is left floating.** |
| 4 | N/C | No internal electrical connection |
| 5 | OUT | Regulated output — connect a minimum 1µF low-ESR ceramic capacitor to this pin. Internal 230Ω pulldown discharges VOUT when in shutdown. |

## Notes

- **EN (pin 3) defaults OFF if floating** (1MΩ internal pulldown to GND) — this is the
  opposite default of many competing LDOs. **If no explicit enable/control signal is planned
  for U4/U6 in `02_architecture.md`, tie EN directly to IN** (always-on) rather than leaving
  it unconnected, or the regulator will never turn on.
- **1µF ceramic required on both IN and OUT** (not optional bypass — this is the datasheet's
  stated minimum for stability, low-ESR recommended), per the "Simplified Schematic" (p.1)
  and Table in §5.6. Confirm the `power_analog`/relevant block's decoupling BOM includes a
  1µF cap at both IN and OUT for each of U4 and U6, not just generic bulk decoupling.
- Pin 4 (N/C) — leave unconnected, no internal die connection (not a thermal pad on this
  package; the X2SON variant has a separate thermal pad pin 5, not applicable to the SOT-23
  package used here).
- No control-logic pin ambiguity beyond EN default-off — this is otherwise a simple
  3-terminal-equivalent LDO (IN/OUT/GND) with EN as the only extra signal.
