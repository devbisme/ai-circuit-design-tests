# AP2112K-1.2TRG1 — 1.2 V, 600 mA LDO with EN (SOT-23-5)

SOURCE: model knowledge (Diodes Inc. AP2112K family, very common small LDO). PDF not
downloaded (diodes.com blocked automated fetch this session, same as AP7361C). Pin table
below is read directly from the installed KiCad symbol's base definition
(`Regulator_Linear:AP2204K-1.5`, which `AP2112K-1.2` `extends`), confirmed present in
`/usr/share/kicad/symbols/Regulator_Linear.kicad_sym`.

| Spec | Value |
|------|-------|
| Package | SOT-23-5 |
| Output | 1.2 V fixed |
| Max current | 600 mA |
| Dropout | ~250 mV typical at full load (AP2112K family class) |
| Input range | ~2.5 V–6 V typical (AP2112K family class) |
| EN pin | Active HIGH (tie to VIN or a supervisory/power-good signal for always-on) |
| Quiescent current | Low (µA class when disabled via EN) |

## Pinout (from KiCad symbol base `AP2204K-1.5`)

| Pin | Name | Type | Function |
|-----|------|------|----------|
| 1 | VIN | power in | Input voltage |
| 2 | GND | power in | Ground |
| 3 | EN | input | Enable, active HIGH — tie to VIN (pin 1) for always-on |
| 4 | NC | no connect | Not internally connected — leave floating or tie to GND for thermal/mechanical only, per typical SOT-23-5 LDO layout practice |
| 5 | VOUT | power out | Regulated 1.2 V output |

## Notes

- U2 in `power_digital`: feeds the iCE40 FPGA's 1.2 V core rail (VCC, VCCPLL). Input from
  3V3_D (post-AP7361C).
- Decoupling per sourced BOM: shares C3/C4 (1 µF input) and C5/C6 (10 µF output) group
  with U1, plus C7 (100 nF bulk).
- **EN pin must not float** — tie directly to VIN for this design's always-on 1.2 V rail
  (no power-sequencing requirement was called out for the FPGA core rail in the
  architecture).
