## Decision: substituted for OT252020MJBA4SL — do not use this part for X1

Architecture R-4 required **≤5 ps RMS phase jitter, or substitute the vetted second source**.
This part's actual datasheet (`datasheets/SX3M20.000B10F20TNN.pdf`, a generic SCTF family
sheet covering multiple frequencies in the same package family) **does not publish a jitter
number anywhere** — checked pages 1–4 (electrical spec table, dimensions, pin table); no
phase-noise or jitter row exists. This means the spec **cannot be confirmed**, which per
architecture's own instruction means: substitute.

**The vetted second source, OT252020MJBA4SL (YXC, C669067), specifies 0.7 ps RMS phase
jitter [12kHz–20MHz]** (`datasheets/OT252020MJBA4SL.pdf`, page 1 spec table, symbol `tpj`) —
7× margin under the 5 ps budget. **This datasheet phase substitutes X1 = OT252020MJBA4SL
in place of SX3M20.000B10F20TNN.** See that part's summary for full detail; this file is kept
only so the coder understands why the sourced-BOM part number for X1 no longer applies.

## Notes

- **Package changes**: this part was SMD3225-4P (3.2×2.5mm); the replacement
  OT252020MJBA4SL is **SMD2520-4P (2.5×2.0mm)** — smaller footprint. Update the sourced BOM's
  footprint reference from `Oscillator_SMD_Abracon_ASE-4Pin_3.2x2.5mm` to
  `Oscillator:Oscillator_SMD_Kyocera_KC2520Z-4Pin_2.5x2.0mm` (confirmed present in the stock
  KiCad footprint library).
- Do not re-source back to this part or an equivalent without a datasheet that actually
  publishes a jitter number — the absence of a spec is the entire reason for the substitution,
  not a specific bad value.
