● I've written JLCPCB-format BOM and pick-and-place files to mcp_out/jlcpcb/,
  but they aren't ready to upload as-is: none of the parts has an LCSC part
  number.

  What's there
  - dual_adc_usb_BOM.csv: 56 lines covering 170 parts, grouped by value and
    footprint, with JLCPCB's columns (Comment, Designator, Footprint, LCSC Part
    #).
  - dual_adc_usb_CPL.csv: 170 placements in mm, with JLCPCB's columns
    (Designator, Mid X, Mid Y, Layer, Rotation). All parts are on the top side.
    I left out the mounting holes H1–H4 because there's nothing to place.

  The CPL file uses the same coordinate frame as the Gerbers, so JLCPCB should
  line the parts up. The Y values are negative because KiCad's Y axis points
  down; JLCPCB normally accepts that.

  Fix before ordering
  1. No LCSC part numbers. The schematic symbols have no LCSC, MPN or
     manufacturer fields, so that column is empty. JLCPCB will make you match
     all 56 lines by hand in their web tool. Adding an LCSC field to the symbols
     would let you regenerate both files in one step.
  2. Parts JLCPCB probably doesn't stock. These are likely global-sourcing items
     with longer lead times, or ones you'd have to consign:
     - The specialised chips: LTC2290, ADA4817, THS4521, FT2232HL, iCE40HX4K,
       W9812G6KH and LM27762.
     - The 0.1% resistors.
     - The Murata TZB4 trimmer capacitors.
     - The Amphenol BNC connectors.

     I haven't checked JLCPCB's stock; this is a judgement from experience.
  3. Rotations are unchecked. They're KiCad's raw values. JLCPCB's part
     orientations often differ from KiCad's for packages like SOT-23, QFN/QFP
     and electrolytics. Check every placement in their preview before
     confirming.
  4. Through-hole parts are included. J101, J201 (BNC), J501 (USB-B) and J601
     (header) are in both files, and through-hole assembly costs extra at
     JLCPCB. Delete those rows if you'll solder them yourself.

  The kicad-pro placement export came out in inches, so I re-ran it with
  kicad-cli in millimetres and converted that file to JLCPCB's layout. The inch
  version is still at mcp_out/pos/board-pos.csv, along with the millimetre file
  board-pos-mm.csv. These are draft files; nobody has signed them off for
  production.
